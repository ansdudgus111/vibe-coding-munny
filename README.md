# Starmp

마감 있는 과제를 작은 단계로 쪼개고, 단계를 끝낼 때마다 별사탕 병이 차오르는 모습을 보며 다정한 코칭을 받는 정적 웹 앱이에요.

**데모**: [배포 주소 입력: https://아이디.github.io/저장소이름/]

## 한 문장 정의

[번아웃 온 대학생]이 [마감 과제가 쌓여 막막한 때]에 [과제를 작은 단계로 쪼개 별사탕 병이 차오르는 모습을 보며 다정한 코칭을 받을 수 있게] 한다. 기존에는 [남은 양과 숫자 중심의 플래너라 죄책감만 커지고 열기 싫어졌다].

> 위 문장은 초안이에요. [본인이 실제로 써본 앱과 불편했던 점]으로 고쳐주세요.

## 쓰는 법

1. 과제 이름, 마감일, 단계(3~5개)를 적어요. 유형(리포트, 발표 등)을 누르면 단계 초안이 채워져요.
2. 프로젝트 색을 고르면 별사탕이 그 색 계열로 만들어져요.
3. 단계를 체크할 때마다 병에 별사탕이 쌓이고, 상태에 맞는 코칭 문구가 나와요.
4. 맨 아래 "돌아보기"에서 주간 목록과 월간 달력으로 모은 별과 마감을 볼 수 있어요.
5. 알림은 과제마다 고를 수 있어요. 이 탭이 열려 있는 동안에만 와요.

## 과제 조건

- 브라우저에서 바로 실행되는 정적 웹이에요. (`index.html` 한 파일)
- 백엔드가 없어요. 기록은 이 브라우저의 `localStorage`에만 저장돼요.
- 화면은 3개예요: 목록(등록, 돌아보기 포함), 병, 완료
- 외부 API와 API 키를 쓰지 않아요.

## 알려진 한계

- 탭을 닫으면 알림이 오지 않아요. (정적 웹의 한계)
- 기록이 브라우저에만 있어서 브라우저 데이터를 지우거나 기기를 바꾸면 사라져요.
