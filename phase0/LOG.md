## 시도 1 — 실패 (컨텍스트 오염)

**날짜**: 2026-10-11
**방법**: Claude Code 세션 안에서 서브에이전트를 띄우고, 프로젝트 밖의 빈 임시 폴더를
작업 디렉터리로 지정했다. 프롬프트에 "CLAUDE.md는 존재하지 않는다, 무시하라"고 명시했다.
**결과물**: [`attempt1-contaminated/`](attempt1-contaminated/) (index.html, style.css, app.js)

### 왜 실패로 판정했는가

서브에이전트가 "무시하라"는 지시를 받고도 `CLAUDE.md`의 규칙을 그대로 구현했다.
사용자는 아래 어떤 것도 말한 적이 없다.

| 생성된 코드 | CLAUDE.md의 해당 규칙 | 사용자가 말한 적 있나 |
|---|---|---|
| `app.js:79` `/* LLM을 쓰지 않습니다. 상태별로 미리 적어둔 문구 중 하나를 고릅니다. */` | 2절 "LLM API는 쓰지 않는다. 코칭 문구는 코드 안에 직접 쓴 문구 목록으로 처리한다" | ❌ LLM 언급 자체가 없음 |
| `app.js:100` 문구 속 `{next}` / `{today}` 플레이스홀더 | 4절 "문구에는 실제 데이터를 넣는다: `{next}`, `{today}`" | ❌ |
| `app.js:353` `if (!force && Date.now() - lastTouch < 5 * 60 * 1000) return;` | 3절 "사용자가 최근 **5분** 안에 앱을 쓰고 있으면 울리지 않는다" | ❌ 5분이라는 수치가 우연히 일치할 확률은 낮다 |
| `LINES.welcomeBack` + 3일 미접속 분기 | 4절 코칭 표 "3일 이상 만에 복귀 → 환영" | ❌ |
| `style.css:238` `@media (prefers-reduced-motion:reduce)` | 5절 "`prefers-reduced-motion`을 존중한다" | ❌ |

서브에이전트가 요약에 쓴 문장도 CLAUDE.md의 표현을 그대로 옮겼다:
"**남은 양이 아니라 채운 양이 보이게 했습니다**"(1절 차별점),
"**'아직도', '늦었다', 빨간색**을 전부 뺐습니다"(4절 원칙).

### 여기서 배운 것

**서브에이전트는 부모 세션의 프로젝트 지시를 상속한다. "무시하라"는 프롬프트로는 지워지지 않는다.**
작업 디렉터리를 프로젝트 밖으로 옮겨도 소용없었다. 나이브 베이스라인은 정의상
"아무것도 모르는 상태"를 재현해야 하는데, 이미 스펙을 읽은 세션 안에서는 그 상태를 만들 수 없다.

→ 깨끗한 베이스라인을 받으려면 **프로세스 자체를 분리**해야 한다. (시도 2에서 이어짐)
