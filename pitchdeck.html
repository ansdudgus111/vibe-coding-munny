Starmp — 과제를 쪼개서, 별을 하나씩 모아요

번아웃 온 대학생이, 마감 있는 과제 여러 개를 챙겨야 할 때, 과제를 3~5단계로 쪼개고 단계를 끝낼 때마다 별사탕이 병에 차오르는 화면으로 진행을 보며 다정한 코칭 문구를 받게 한다. 기존에는 유료화되는 일정 관리 앱은 핵심 기능이 잠기거나 부담스럽고, 무료 플래너는 목록과 숫자뿐이라 진행이 눈에 보이지 않아 열기 싫어졌다.

데모 · 1.5분

단계 체크 → 병이 차오름 + 코칭, 이 하나가 핵심 기능

화면은 3개뿐이다 — 목록(등록 + 돌아보기) → 병(단계 체크 + 코칭 + 알림) → 완료(회고). 이 순서대로 실제 배포 페이지를 열어 시연한다.

📸 확인 필요 — 아래 3장을 실제 데모 중 캡처해 이 자리에 넣을 것: ① 목록 화면(등록 폼 + 담고 있는 병 목록 + 돌아보기) ② 병 화면(별사탕 병 + 알림 미리보기 모달) ③ 완료 화면(가득 찬 병 + 회고 입력)
나이브 베이스라인 · 1분

같은 한 줄을 세 번 던져봤고, 세 번 다 같은 패턴이 나왔다

나는 내가 해야되는 일을 시각적으로 보여주고 목표를 설정하면 팝업으로 지속적으로 알려주는 걸 만들고 싶거든 내가 이번학기 번아웃이 와서 스크린 타임은 느는데 할 일은 똑바로 안 됐거든 그래서 그런걸 좀 힐링하고 고치기 위해서 가시적으로 할일을 할 수 있도록 도와주고 힐링할 수 있는 앱을 만들고 싶었어

Claude Code로 같은 문장을 두 번 재현하려 했지만, 두 번 다 "오염 의심"으로 무효 처리했다 — 이미 CLAUDE.md를 읽은 세션/서브에이전트였기 때문이다 (상세: 슬라이드 4). 대신 과제 예시 프롬프트("대학생용 투두리스트 앱 만들어줘")로 진행한 시도에서 AI가 임의로 정한 것:

  • 투두 항목에 카테고리(학업/개인/동아리)·우선순위(낮음/보통/높음)를 요청 없이 추가
  • "어떻게 해야 잊지 않고 완료할지 방법을 생각해봐"(브레인스토밍 요청)에 설명 없이 바로 알림·스트릭·등급 뱃지 시스템을 구현해버림 — 질문과 구현을 구분하지 못함
  • "힐링 컨셉"이라는 추상적 지시를 톤으로 해석하지 않고 "힐링"이라는 단어 자체를 제목에 그대로 박아넣음 (키워드 치환 ≠ 개념 번역)

결론 · 0.5분

AI는 과거 맥락을 스스로 의심하지 않는다

AI가 믿을 만했던 영역

기존 디자인 토큰 재사용, 하드 제약을 스스로 점검하고 대안을 내는 것

사람 개입이 꼭 필요했던 영역

"됐다"는 자체 보고의 코드 대조 검증, 과거에 되돌린 패턴이 다른 말로 재등장했을 때 알아채는 것

다음 프로젝트 개선점 — Phase 0처럼 "AI가 아무것도 모르는 상태"가 필요한 작업은 같은 세션의 서브에이전트나 작업 폴더 분리로 흉내 낼 수 없다. 처음부터 완전히 분리된 새 프로세스(새 터미널/새 창)로 시작해야 한다.
